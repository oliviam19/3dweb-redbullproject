Project Details
This project explores the integration of interactive three-dimensional product visualisation within a web interface. This prototype website features three 3D models of Red Bull cans that respond to user scrolling; rotating as the user navigates the page. This interaction simulates the experience of examining a product in physical space, introducing an element of novelty. By combining visual communication and interaction design, the project investigates how emerging 3D web technologies can enhance user engagement and product exploration while maintaining usability and performance.
This website was first designed in Figma. The cans were modelled and animated in Blender, and graphic elements were created on Adobe Photoshop and Illustrator. I then coded the HTML, CSS, and JS using VSCode and exported through GitHub.
